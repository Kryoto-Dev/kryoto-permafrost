# Security

Report anything that could harm a player privately, through
[GitHub's security advisories](https://github.com/Kryoto-Dev/kryoto-permafrost/security/advisories/new).

Worth reporting: a repack that writes outside its install folder, a setup that runs something the
player did not agree to, and anything that makes the check at the end of a freeze pass on a repack
that installs differently.

A setup is a program, and anyone can make one with this tool, so a setup made with it says
nothing about who made it. Only run setups from people you trust. This tool never adds the
`- kryoto` ending that marks Kryoto's own downloads.
